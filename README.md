# calc. - The Calculator Better Than Yours
"calc." is a calculator I made to be better than the default calculator app on your PC. It has a lot of features, maybe even too much. You can choose out of 26 themes and you can make your own custom ones! "calc." is currently only available as a ".html" file. "calc." has a site now: https://ege-u.github.io/calc/calc.html
